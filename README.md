# go-concurrency-practice

Демонстрационный проект к отчёту по учебно-ознакомительной практике
(2 семестр магистратуры, РГЭУ (РИНХ)). Иллюстрирует модель конкурентности
языка Go: горутины, каналы и средства синхронизации из пакета `sync`.

## Что это

Пул воркеров (worker pool) — «бригада» из трёх горутин-работников, которые
параллельно разбирают задания из общего канала и складывают результаты
во второй канал. Каждое задание — число, результат — его квадрат.

## Требования

Go версии 1.14 или новее.

## Запуск

```bash
go run main.go
```

Ожидаемый вывод — квадраты чисел от 1 до 9 (порядок может меняться от запуска
к запуску, так как воркеры работают параллельно):
